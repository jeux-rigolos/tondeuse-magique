Si la manette n'est pas détectée

  1. Dans Réglages Système → Bluetooth sur le Mac, vérifie que la manette est connectée.
  2. Clique dans cette page puis appuie sur A (ou un autre bouton), et bouge le joystick. Certains navigateurs n’exposent la manette au site qu’après une pression.
  3. Essaie cette même page dans Chrome et dans Safari pour comparer.
  4. Si elle apparaît ici mais pas dans le jeu, indique le nom, le nombre d'axes et le nombre de boutons affichés. Si rien n'apparaît, indique le navigateur et le modèle de manette.

Le test reste local à ton navigateur et n’envoie aucune information de la manette à un serveur.
